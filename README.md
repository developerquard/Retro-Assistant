# Retro

NOTE: It's a portfolio project just meant to be showcased as proof of my knowledge of AI integration and Client-Side .exe executables. (You can use it if you want to use it anyway ☺ )

**Your personal AI desktop assistant.**

Retro is a Windows desktop AI assistant designed to make everyday computer interactions more convenient through conversation, voice interaction, and a lightweight graphical interface.

Rather than being limited to a traditional chat window, Retro aims to feel like an assistant that lives on your desktop.

## Features

* **AI Conversations** — Interact with AI models through a desktop interface.
* **Voice Interaction** — Communicate with Retro using voice.
* **Floating Orb** — A compact assistant interface that can stay accessible while using your computer.
* **Media-Reactive Modes** — Visual modes that respond to music and media.
* **Application Launching** — Open applications through assistant interactions.
* **Document Generation** — Generate documents through conversations.
* **Conversation Context** — Maintain conversational context across interactions.

## Interface

Retro features a PySide6-based graphical interface, including its main assistant window and floating orb.

## Technology

* Python
* PySide6
* AI model integration
* Local application storage

## Requirements

* Windows
* Python 3.11 or newer
* Required Python dependencies

## Project Status

Retro is an experimental project under active development.

Some features may change, behave inconsistently, or require further refinement. It is not currently intended to be production-ready.

## Building

Retro includes a build script for packaging the application into a Windows executable.

## Project Goals

Retro is an exploration of what a lightweight, desktop-based personal AI assistant can become, combining conversational AI, voice interaction, and desktop functionality into one application.
